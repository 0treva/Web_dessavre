# Imágenes de publicidad

Guarda aquí las piezas publicitarias de productos y campañas.

- Formato recomendado: `.webp` o `.jpg`.
- Proporción recomendada: `16:9` para banners o `4:5` para tarjetas.
- Nombres sugeridos: `auto-01.webp`, `vida-01.webp`, `hogar-01.webp`.
- Optimiza cada imagen a menos de 300 KB antes de publicarla.

Los cinco videos existentes se conservan en la sección `#campanas` de `index.html` mediante sus URL actuales. Las imágenes `campana-01.jpg` a `campana-05.jpg` funcionan como portadas ligeras para esos videos.
